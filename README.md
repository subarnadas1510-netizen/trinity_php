# 🏥 Trinity Hospital Management System

## 📖 Overview

The **Trinity Hospital Management System** is a web-based hospital management application developed to simplify the process of appointment booking and patient record management. The project provides a user-friendly interface for patients to book appointments online, while allowing administrators to manage appointment records efficiently through a secure admin panel.

This project was developed as an academic project to demonstrate the implementation of CRUD (Create, Read, Update, Delete) operations using PHP and MySQL, along with a responsive frontend designed using HTML, CSS, Bootstrap, and JavaScript.

---

## ✨ Features

* 🏥 Modern and responsive hospital homepage
* 📅 Online appointment booking system
* 🔐 Secure admin login panel
* 📋 View all patient appointment records
* 🔍 Search patient records by ID
* 👁️ Display appointment details
* 🗑️ Delete patient records
* 📱 Responsive design using Bootstrap
* 💾 MySQL database integration using PHP

## 🗄️ Database

The project uses a MySQL database to store patient appointment details. PHP prepared statements are used for secure database operations and to protect against SQL injection attacks.

## ▶️ Installation

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import the MySQL database into phpMyAdmin.
5. Update the database credentials in `dbconnect.php` if required.
6. Open your browser and visit:

   ```
   http://localhost/Work/
   ```
